# temporal.io
## link: https://docs.temporal.io/

Temporal은 장시간, 그리고 실패 가능성이 있는 업무 프로세스를 안정적으로 실행하는 워크플로 오케스트레이션 프레임워크이다.

업무에서도 사용중이며, 해당 프레임워크는 서버가 재시작되거나 외부 API가 실패하더라도, 실행하던 업무를 기억하고 중단 지점부터 이어서 처리해주는 시스템이다.

예를 들어 주문 생성이 들어갔다 치면 결제 승인, 크레딧 차감, 위성영상 요청, 알림 발송 등 절차가 존재하는데, 중간에 장애가 발생하면 직접 구현해야하는게 많다.

재시도, 타임아웃, 현재 상태 저장, 대기, 재시작 등, 손수 구현(AI 시키긴 함)을 하는건 불필요하고 또 인적 오류가 발생할 수 있다. 그래서 이 Temporal을 쓰는게 좋다.

이번에 위성영상기반 지반침하를 구현하면서 좀 들여다보게 됐는데, TechStack에서 중요점으로 판단되어 Docs기반의 간단한 스터디를 진행한다.
