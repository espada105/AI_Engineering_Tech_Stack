# Bitbucket Pipeline 

## Case
SoftWareTeam의 백엔드 개발자 인턴분이 우리측에다가 PR을 올리셨고, 나는 해당 코드를 리뷰한 후에 Merge를 진행했다.
-> Bitbucket Pipeline에서는 "We couldn't clone the repository. Try rerunning the pipeline. Refer to the Troubleshooting runners document for help resolving the issue."
라는 SystemMessage에러가 발생했고, llm에 서버에 접속하여 확인해보니 동일한 파일이 존재했다. 순간 UUID가 우주의 기운을 받아 아다리로 똑같이 만들어졌나라고 생각했는데, 애초에 Pipeline은 임시파일로 중단없이 진행이 됐을때, 삭제가 되는게 일반적이고, 이 상황에서는 직전 Pipeline을 돌리다가 중지하여 임시 파일이 삭제되지 못하고 남은 것이 원인이었다. 

## Solution
Bitbucket Pipeline이 있는 해당 서버에서 임시 파일을 삭제하거나, 귀찮으면 그냥 Rerun 돌리면 된다.
임시로 존재하던 파일은 SystemError로 실패 -> 삭제. 된 것이기에 다시 돌리면 그냥 돌아간다.
